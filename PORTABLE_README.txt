3080工具箱 1.8.1 免安装版

1. 将 ZIP 完整解压到一个可写目录，不要直接在压缩包中运行。
2. 双击 toolbox_3080.exe。不要只移动 EXE，其他文件夹也是运行必需的。
3. 屏幕翻译默认使用 Hy-MT2-7B Q4_K_M，模型、OCR 和 GPU 运行库均已包含。
4. RTX 3080 10GB 可使用 CUDA GPU；显存不足时请先关闭占用显存的程序，或选择 CPU。
5. 不需要安装 Flutter、Python、CUDA Toolkit 或在线翻译服务。GPU 模式仍需要可用的 NVIDIA 显卡驱动。
6. 退出程序或点击“释放显存”可停止本地翻译模型。

此版本不创建安装项、开机启动项或桌面快捷方式。运行时会使用 Windows 临时目录。
不要同时运行多个加载翻译模型的实例，以免显存不足。
